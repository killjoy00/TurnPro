# Repository agent instructions

## Portfolio mobile releases

Use the [mobilereleases registry and dashboard](https://github.com/killjoy00/mobilereleases) and [release request instructions](https://github.com/killjoy00/mobilereleases/blob/main/mobile-releases/RELEASE_REQUESTS.md) for mobile release work. Mobile is a future target. Do not create a store application, signing credential, or publishing workflow merely to populate the dashboard. Register the verified route when mobile delivery is authorized. Keep existing app-specific requirements and require explicit owner approval for production publishing. Never expose credentials or private account information.
